# crestron-ai-skills

Search, inspect, and install skills from the [CrestronAISkills](https://github.com/Crestron/CrestronAISkills) registry, directly from Claude Code or Cowork.

## What it does

Adds one skill (`crestron-ai-skills`) that Claude loads when you ask to browse, search, or install skills from the CrestronAISkills registry. It can:

- Search the registry by keyword, tag, or author
- Show full details for a specific skill
- Install a skill so it's available in future sessions
- List skills you already have installed

## Usage

Just talk to Claude, e.g.:

- "Search the Crestron skills registry for AV"
- "Get info on the example-skill Crestron skill"
- "Install the example-skill Crestron skill"
- "What Crestron skills do I have installed?"

No API keys or auth required — the registry is a public GitHub repo / Pages site.
